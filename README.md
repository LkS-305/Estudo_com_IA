# Estudo_com_IA

Notebooks de estudo que uso para me preparar para as provas da faculdade. Cada notebook é um único
arquivo HTML, interativo e offline, gerado com IA a partir do material da disciplina (slides, listas,
provas antigas): traz resumos dos capítulos, exercícios e provas resolvidas, simuladores e widgets
interativos, busca e acompanhamento de progresso. Para usar, basta baixar o `.html` e abrir no navegador.

> O material original de cada matéria (pasta `Conteudo/`) e os arquivos de build não são versionados —
> o repositório guarda apenas os notebooks finais.
